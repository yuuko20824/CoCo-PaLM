# CoCo-PaLM

Simulation code for **CoCo-PaLM (Cognitive Control, Production, and Learning Model)**.

For more details, please refer to our paper: Hu, S., Verguts, T., & Nozari, N. (2026). A learning account of cognitive control in word production: A path to new insights into the domain generality of control [Manuscript in preparation].

## Contents

| Notebook | Simulation | Task |
|---|---|---|
| `CN.ipynb` | Simulation I | Continuous naming (CN) |
| `BCN.ipynb` | Simulation II | Blocked-cyclic naming (BCN) |
| `PWIandDualTask.ipynb` | Simulations IV and V | Picture-word interference (PWI); PWI interleaved with the prime-probe (PP) task |

## Requirements

The code was developed and tested with Python 3.11. Earlier versions of Python may cause errors and are not guaranteed to work.  

Required packages:
```
numpy pandas scipy matplotlib joblib openpyxl
```
